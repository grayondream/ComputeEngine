# P0.5 接口冻结 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 P0.5 要求的全部公开接口补齐为可编译、可实例化、默认行为明确的契约，并在 C ABI + 插件版本上完成冻结。

**Architecture:** 以头文件为主：每个模块只声明接口、默认方法、空实现与少量纯数据结构；不实现真实 kernel/调度/训练/校验逻辑。`ie_core` 继续承载核心契约，`ie_cpu` 追加 C ABI 实现。所有可选层默认关闭，默认方法统一返回 `Error::unsupported(...)`。

**Tech Stack:** C++20、CMake + Ninja、GoogleTest 1.17、现有 `Status`/`Result<T>`（C++20 自研）。

**Spec:** `docs/superpowers/specs/m1-bootstrap/p0.5-interface-freeze.md`（设计权威：`docs/readme.md` §1、§3–§12、§14–§16）

## Global Constraints

- C++ 标准 `C++20`，`CMAKE_CXX_EXTENSIONS OFF`，命名空间统一 `ie`；`-Wall -Wextra -Wpedantic` 必须无警告。
- 代码在 `src/`，测试在 `tests/`，文档在 `docs/`；头文件一律 `#pragma once`，与实现同目录。
- 不引入 MLIR、vcpkg、JSON 库、gRPC/protobuf 等外部依赖；P0.5 只做声明与空实现。
- 默认行为：可选/未实现方法返回 `Error::unsupported("<feature> not implemented in P0.5")`；纯查询/生命周期方法返回 `{}`/空容器。
- 冻结版本：`IE_API_VERSION_MAJOR=0`、`IE_API_VERSION_MINOR=1`、`kApiVersion="0.1"`；插件 `PluginMeta.api_version` 必须通过兼容性检查。
- P0-MVP 已冻结的调用不得破坏（`Backend::device()` 返回 `Device` 值、`Graph::backward_graph` 为 `std::shared_ptr<Graph>`、`Status`/`Result` 自研）。
- 每个 Task 先写失败测试、再实现；结束时 `ctest --test-dir build --output-on-failure` 全绿并独立提交。
- 每新增一个测试文件，必须加入 `tests/CMakeLists.txt` 的 `add_executable(ie_tests ...)` 源列表；头文件任务不需要改 `CMakeLists.txt` 源列表。

## Review Focus

1. **纯接口的默认实现**：任何未实现方法都必须返回明确的 `Unsupported`/空值，不能返回未初始化数据或崩溃。
2. **特性门控默认值**：`FeatureFlags` 的 6 个默认 true 项与其余 false 项必须逐项符合 §12.3，避免实验/训练路径被默认打开。
3. **插件版本与重复注册**：API 不兼容的插件必须被拒绝（`InvalidArgument`），重复注册返回 `AlreadyExists` 且保留原件。
4. **C ABI 边界**：`ie_create_backend("cpu", ...)` 成功，未知 kind/空参数返回 `nullptr`，`ie_destroy_backend(nullptr)` 安全，`ie_api_version()` 恒为 `"0.1"`。
5. **跨层默认值不破坏 P0**：`EngineConfig` 新增 flags/hybrid/validation 默认值后，原有 `(a+b)*3` e2e 与 demo 仍通过。
