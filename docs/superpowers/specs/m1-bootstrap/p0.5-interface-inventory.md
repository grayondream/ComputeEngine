# P0.5 冻结接口清单(Interface Inventory)

> 来源:`docs/superpowers/plans/2026-11-04-p0.5-interface-freeze.md` Task 1–10。
> 冻结版本:**`0.1`**(`IE_API_VERSION_MAJOR=0`、`IE_API_VERSION_MINOR=1`、`kApiVersion="0.1"`)。
> 本清单覆盖 P0.5 新建/修改的全部 79 个公开头文件,按契约组(Task 1–10)列出路径、公开符号与默认行为。默认行为统一遵循:
> - 生命周期/配置/纯查询方法返回 `{}` 或空容器;
> - 未实现的功能性方法返回 `Error::unsupported("<feature> not implemented in P0.5")`;
> - 纯接口(plugin/backend/executor 等)只声明纯虚函数,由后续里程碑实现。
>
> `Status` 是规范的“无返回值结果”;设计中写作 `Result<void>` 的签名统一映射为 `Status`。
